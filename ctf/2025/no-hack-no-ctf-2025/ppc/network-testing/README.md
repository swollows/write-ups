# Network Testing 문제 해결

## 문제 분석

네트워크에 n개의 서버가 있고, 두 개의 메인 서버 x, y가 있습니다. 각 서버는 ci만큼의 테스트 지속 시간을 가지며, 총 합은 k를 초과할 수 없습니다.

메인 서버들이 신호를 보내고, 서버가 디버그 모드에 있는 동안 신호를 받으면 이익을 얻습니다. 두 메인 서버로부터 모두 신호를 받으면 2개의 이익을 얻습니다.

## 핵심 아이디어

1. **최단 거리 계산**: 각 서버에서 메인 서버 x, y까지의 최단 거리를 구합니다.
2. **업그레이드 개념**: 각 서버에 대해 두 가지 업그레이드를 고려합니다:
   - 업그레이드 1: 0 이익 → 1 이익 (비용: min(dist_x[i], dist_y[i]))
   - 업그레이드 2: 1 이익 → 2 이익 (비용: max(dist_x[i], dist_y[i]) - min(dist_x[i], dist_y[i]))
3. **탐욕적 접근**: 효율성(이익/비용) 순으로 정렬하여 탐욕적으로 선택합니다.

## 알고리즘

1. 다익스트라 알고리즘으로 각 서버에서 x, y까지의 최단 거리를 계산
2. 각 서버에 대해 가능한 업그레이드 옵션들을 생성
3. 효율성 순으로 정렬
4. 각 서버의 현재 단계를 추적하며 순차적으로 업그레이드

## 시간 복잡도

- 다익스트라: O(n² log n)
- 정렬: O(n log n)
- 전체: O(n² log n)

## 예제 결과

- 테스트 케이스 1: 6
- 테스트 케이스 2: 3
