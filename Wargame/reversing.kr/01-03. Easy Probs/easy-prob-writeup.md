# Reversing.kr Write-ups

## 1. Easy Crack

### 문제 설명
입력해야 하는 문자열 찾기

### 풀이 과정
1. 파일 다운로드 후 실행 시 간단한 Windows 기반 입력창이 출력됩니다.
2. 입력창에 문자열 입력 후 [확인] 버튼을 누르면 오류 메시지 `Incorrect Password` 가 출력됩니다.
3. 디컴파일러 실행 후 `MessageBoxA` 함수 호출부를 확인합니다.
4. 함수부 진입 후 분기문 내 문자열 비교 내용을 확인합니다.
5. 4번에서 확인한 문자열을 순서대로 다시 정리해서 입력창에 입력하면 정답입니다.

## 2. Easy Keygen

### 문제 설명
시리얼넘버 `5B134977135E7D13`에 대한 이름값 찾기

### 풀이 과정
1. 본 프로그램은 Windows 기반 CLI 프로그램으로 실행 시 이름/시리얼넘버 순서로 입력 후 비교한 후 프로그램이 종료됩니다.

2. `main` 함수에서 이름값 입력 후 `sprintf` 함수 호출하면서 시리얼넘버 생성하는 로직을 확인합니다.
   - 로직 동작 방식:
     - 0~2까지 동작하는 카운터와 `arr[3] = {16, 32, 48}` 배열 선언
     - 문자열을 순회하면서 카운터를 1씩 증가시켜 배열 요소와 이름 문자 1개를 XOR 연산 후 시리얼넘버 생성

3. 해당 로직 이후 시리얼넘버를 입력한 다음 이름을 통해 생성한 값과 비교하여 일치 시 통과합니다.
4. 정답은 시리얼 번호 문자열을 2개씩 끊어서 16진수화 한 다음 2번의 연산과정을 그대로 수행합니다.

## 3. Easy Unpack

### 문제 설명
주어진 문제의 OEP 주소 확인 (README 파일에 플래그 정보 있음)

### 풀이 과정
1. 본 프로그램은 특정 패커로 패킹된 프로그램으로 OEP 주소를 확인할 수 없습니다.
2. PE 분석 프로그램인 PEiD를 이용하여 프로그램 분석 시 UPX로 패킹된 정황을 확인할 수 있습니다.
3. PEiD의 플러그인 중 PEiD Generic Unpacker를 활용하여 OEP 주소를 추출합니다.
